# 序仓 · 库存动态管理

面向现货、生产订单、FBA 在途和 FBA 在售的中文库存管理页面。

## 本地运行

需要 Node.js 22 或更高版本。安装锁定依赖后启动；启动时自动构建静态网站。

```sh
cd /workspace/management-inventory
npm ci
npm start
```

默认监听 3000 端口，可用 `PORT` 调整。使用 `npm test` 验证库存业务规则。

## 使用流程

首次进入为明确标记的示例空间。点击「开始记录真实库存」后新增产品，录入产品名称、货号、MSKU、FNSKU、各类期初库存和 FBA 在售预警值。MSKU 唯一，库存按 MSKU 管理。

1. 新增生产订单：录入订单编号、产品、数量和预计货好日期。默认为提前 **7 天**在页面提醒，逾期未入库持续提醒；日期采用北京时间。设置中可调整提前天数。
2. 确认生产入库：整笔订单数量加入现货，生产中数量归零。请核实实际收货数量一致后再确认。
3. 新增出货计划：预占可用现货，不减少实际现货。现货不足时拦截。取消待出货计划释放预占。
4. 确认实际出货：现货扣数，等量增加 FBA 在途；每笔出货只执行一次。
5. 确认 FBA 到仓：在途转入在售；每笔到仓只执行一次。当前按整笔确认，不支持分批签收。
6. 库存调整：处理额外现货入库、现货损耗、FBA 销售扣减。无关联出货单的期初在途可选择「期初在途到仓」。所有实际库存变化保留流水。

「可用现货」= 实际现货 − 待出货计划预占。低库存预警按 FBA 在售数量低于产品预警值判断。

## 数据与边界

- 数据使用当前浏览器同源 localStorage 保存，刷新后保留。尚无服务器数据库、账号系统和跨设备同步。
- 定期导出 JSON 备份。导入备份会验证库存结构，确认后替换本地数据。切换示例/真实空间同样需要明确确认。
- 货好提醒仅在页面内展示，没有邮件、微信或关闭页面后的后台推送。
- 新订单和出货计划需录入页面；聊天内容不会自动同步到该浏览器。没有接入亚马逊 API，FBA 销售及到仓需手工确认。
- 单据可同编号多款产品分行录入；库存操作逐行确认。
- 初版不支持部分入库、分批出货、退货或自动对账。正式多人长期使用前应接入持久化数据库、认证和备份机制。

## 验证

`npm test` 包含库存完整流转、预占与取消、重复操作拦截、无效数量/日期拦截、备份校验、7 天提醒日期边界和期初在途到仓测试。

## 上传表格

点击侧边栏或顶部的「上传数据」。首次使用先退出示例空间。支持 Excel `.xlsx`（可选工作表）及 CSV（UTF-8 / GB18030），每个文件最多 5 MB、2000 行、60 列。

1. 选择国内库存、生产订单或出货计划，下载对应 CSV 模板；请用真实记录替换示例行。
2. 选择文件，自动识别常见列名，也可手动匹配表格列。第一行为表头。
3. 检查前 20 行预览和全部行的校验结果。错误信息标注表格行号。
4. 核对并确认后一次性写入。任一行错误则整批不写入。确认时按最新库存再次验证。

国内库存仅新增产品，不覆盖已有 MSKU；订单和计划按 MSKU 关联产品，重复单号拦截。出货计划累计检查预占库存。生产订单日期支持 Excel 日期单元格或 `YYYY-MM-DD`、`YYYY/MM/DD` 文本。编号列建议设为文本以保留前导零。

上传文件在浏览器内处理，不会传给服务器。公网部署请参阅 [DEPLOY.md](DEPLOY.md)。执行 `npm run build` 生成可托管的 `dist` 静态网站。

## 国内库存模板与面板

原「期初库存」模板改为「国内库存」，侧栏进入「国内库存」可查看完整十列：产品名称、货号、MSKU、FNSKU、现货数量、在做订单数量、现货订单号+数量、在做订单号+数量、在做订单号+货好日期、国家。多笔订单在单元格内分行展示。

下载「国内库存模板」后，一行填写一款产品：订单明细用 `PO-001+60；PO-002+40`，在做日期用 `PO-003+2026-12-01`。每列内多笔用分号或换行分隔；每笔在做订单都必须有对应货好日期。现货明细合计须等于现货数量，在做明细合计须等于在做订单数量。

在做明细直接生成生产订单并参与提醒和预测，不额外保存一份汇总以免重复计数。确认入库时从在做转入现货订单明细。指定生产订单出货时优先扣该订单的现货；普通出货、损耗会保护其他待出货计划已预占的订单批次。新模板仅处理国内库存，FBA 数量默认 0；旧模板额外的 FBA 列仍可兼容读取。

旧版浏览器库存不清空；缺少订单来源的现货标为「未关联订单」。点击「补充现货订单」可补录关联，只改变明细，不改变库存总数，并记录一条零数量变动流水。重复 MSKU 仍不覆盖，当前不支持以整表反复覆盖已有实物库存。

## 编辑与删除

库存总览/国内库存、生产订单、出货计划、每周销量、历史成本、实际账单、日本预估和英德预估均提供「编辑」「删除」。点击编辑打开已填好原值的表单，修改后保存；取消不会写入。国内库存中的在做数量/日期来自生产订单，请到对应订单编辑。现货总数和现货订单数量须同时保持一致。

实际账单和预估以整票编辑/删除；表单展开本票各款产品及费用参数，可复制或移除某条明细，保存时重新校验并分摊。分摊头程和利润属于计算结果，通过修改输入数据更新。英德单价单位以本币、美元、人民币分别标明。

已处理订单修改数量或状态时，先撤回原库存流转，再按新值处理。删除待出货计划释放预占；删除已出货记录退回现货并扣在途；删除已到仓记录退回现货并扣在售。生产订单已入库数量撤回时扣原 PO 现货。库存已使用、批次预占冲突或仍有关联业务的情况会阻止整次操作，原数据保持不变。单纯修改备注、价格、店铺、ETA 不重复计数。

删除弹窗展示所选记录并要求勾选确认。删除产品须先处理其关联业务，产品库存余额和该产品流水也一并移除。其他业务记录的修改/删除保留库存修正流水；流水仅可编辑关联原因，数量由业务操作生成，不直接删除。数据只保存在本浏览器，操作前建议导出备份。

## 最新五类模板（2026-10-24）

网站「上传数据」可单独下载，也可点击「下载五类模板合集」获得同一版本的五个 CSV，均按用户提供的列顺序保留。模板自带示例，上传前替换为实际数据；编号列在 Excel 中设为文本。

| 模板 | 列数 | 导入行为 |
| --- | --- | --- |
| 国内库存 | 10 | 新增产品和国内订单，新增末列国家；重复 MSKU 不覆盖 |
| FBA库存 | 8 | 独立模板，省略原表空白占位列；替换 FBA 快照，不改国内现货及生产订单 |
| 出货计划 | 27 | 保留货件、采购单、箱规、重量、仓库、ASIN、链接及申报价格；先存草稿 |
| 实际头程账单 | 31 | 保留美元、英镑和人民币原币种及全部物流字段，独立保存待核算 |
| 每周销量 | 5 | 店铺、SKU、周期开始、周期结束、销量；SKU 匹配唯一 MSKU 或唯一货号 |

建议先导入国内库存，再导入 FBA 库存。FBA 也可独立建档为国内库存 0 的产品。FBA 在途日期按 `20+2026-12-01；30+2026-12-15` 填写，合计须等于在途数量；日期待补可留空。相同快照不累加数量；同批重复 MSKU 拒绝。存在出货单跟踪的在途时拒绝快照覆盖，请在出货计划处理到仓后更新。日期明确的快照在途参与补货预测，过期/未知日期不算可靠供给。

新版出货模板没有计划出货日期，因此上传后在「出货计划 → 待补日期的出货草稿」查看、编辑、删除；点击「生成出货计划」补日期，库存足够且关联生产订单有效后才预占库存。未生成前不扣数、不预占。同票同店铺同产品不重复新增。旧版含计划日期的 CSV 仍可导入。

新版账单在「头程费用与利润 → 原始头程账单（待核算）」展示全部 31 列，允许逐行编辑、删除。金额空白表示待补，保留差异的原始正负号；不推测汇率或币种，不将原始行金额重复汇总为整票费用。因缺少确认的人民币总费用和采购成本，原始账单不直接进入加权成本；继续使用独立的「实际费用核算（人民币）」模板提供确认结果。原有成本账单和历史加权数据保持有效。

仓库路径：`templates/库存管理模板合集.zip`；更新的网站部署包仍为根目录 `site.zip`。旧网址请先导出备份，再部署到同一个 Netlify 项目。页面底部「模板更新：2026.10.24」可帮助识别新版。
